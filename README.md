# 📚 MyLMS – Learning Management System Android App

MyLMS is a fully-functional Learning Management System built in **Kotlin** using **Firebase Firestore**, designed for both **Admin** and **Normal Users**. It allows course creation, user management, content uploading, and performance tracking – all within a modern Android interface.

---

## ✨ Features

### 👤 User Roles
- **Admin (admin2@gmail.com / abhi1234)**  
  - Create new courses (title, summary, duration, type, category)
  - Invite users by email
  - Upload course content (video, PDF, DOC, quizzes, books)
  - View analytics (user scores, rankings, question-wise accuracy)

- **Normal Users**
  - Access only eligible courses (default: "FREE")
  - View uploaded content within their allowed courses
  - See personal score & rank only

---

## 🧠 Tech Stack

- **Kotlin + Android (XML, ViewBinding)**
- **MVVM Architecture**
- **Firebase Firestore** – Realtime database
- **Firebase Auth** – Secure login system
- **Google Sign-In**
- **RecyclerView** – Course listing
- **Animations** – UI polish and bounce effects
- **Dynamic Role-based Navigation**
